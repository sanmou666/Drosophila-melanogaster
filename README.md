# Drosophila melanogaster

Transcript annotation and selected transcript sequences.

## Files

- `Drosophila_Final_Cleaned_transcripts_exons.gtf.gz`: GTF annotation assembled from 25,582 *Drosophila melanogaster* transcriptomes. Contains 189,353 distinct transcript IDs.
- `Super_housing_keeping_67_sequences.fasta`: Sequences of the 67 transcripts detected as expressed in the greatest number of the 25,582 *Drosophila melanogaster* transcriptomes.
