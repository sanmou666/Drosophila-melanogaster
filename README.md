# Drosophila melanogaster

Transcript annotation and selected transcript sequences.

## Files

- `Drosophila_Final_Cleaned_transcripts_exons.gtf.gz`: GTF transcript and exon records extracted from `2_merged.gtf` by exact `transcript_id` matches to `Drosophila_Final_Cleaned.gtf`. Contains 189,353 distinct transcript IDs, 189,354 transcript records, and 1,127,917 exon records. All requested IDs were found and have exons. The source duplicate transcript record for `FBtr0084081` is retained. Decompress the gzip file before use.
- `Super_housing_keeping_67_sequences.fasta`: 67 transcript sequences extracted by exact ID matches from `transcripts.fasta`, in the requested order, with original FASTA headers and sequence content preserved.
